# 晨星风格箱 (Morningstar Style Box)

基于华泰证券研报《晨星风格箱基于基金持仓数据并根据规模、价值成长特性确定基金风格》(2020-08-21) 的Python完整复现项目。

## 项目结构

```
morningstar_stylebox/
├── data/              # 数据存放目录
├── ipynb/             # Jupyter复现文件
│   └── morningstar_stylebox_demo.ipynb  # 完整复现notebook
├── output/            # 输出结果（图表、CSV）
├── source/            # 核心模块
│   ├── __init__.py    # 包初始化
│   ├── data_loader.py # 数据获取（efinance→akshare→baostock）
│   ├── factor.py      # 因子计算（规模+价值-成长，严格研报公式）
│   ├── backtest.py    # 绩效计算（收益率、夏普、回撤等）
│   ├── plot.py        # 可视化（3×3风格箱、散点图、净值曲线）
│   └── utils.py       # 工具函数
├── main.py            # 主程序入口（命令行运行）
└── README.md          # 项目说明
```

## 研报算法核心

### 1. 规模因子

**股票的规模得分 y:**
```
y = 100 × [1 + (ln(Cap) - ln(MST)) / (ln(LMT) - ln(MST))]
```
- `Cap`: 股票总市值
- `MST`: 中小盘门限 — 累计市值占比≥90%的边界股票市值
- `LMT`: 大中盘门限 — 累计市值占比≥70%的边界股票市值

**风格判定:**
| 得分范围 | 风格 |
|---------|------|
| y < 100 | 小盘股 |
| 100 ≤ y ≤ 200 | 中盘股 |
| y > 200 | 大盘股 |

**基金的规模得分 Y:** Y = Σ(wi × yi) / Σ(wi)，即持仓股票规模得分的占比加权平均

### 2. 价值-成长因子

**价值得分（5个子因子，各0.2权重）:**
1. 预期收益/股价 (E/P = 1/PE)
2. 每股净资产/股价 (B/P = 1/PB)
3. 每股营收/股价 (S/P = 1/PS)
4. 每股现金流/股价 (C/P)
5. 每股分红/股价 (D/P = 股息率)

**成长得分（4个子因子，各0.25权重）:**
1. EPS增长率
2. 每股净资产增长率
3. 每股营收增长率
4. 每股经营现金流增长率

**VCG综合得分:** VCG = 成长得分 - 价值得分

**股票的价值-成长得分 x:**
```
x = 100 × [1 + (VCG - VT) / (GT - VT)]
```
- `VT`: 价值-混合门限（VCG的33.3%分位数）
- `GT`: 混合-成长门限（VCG的66.7%分位数）

**风格判定（γ=0.5）:**
| 得分范围 | 风格 |
|---------|------|
| x < 125 | 价值型 |
| 125 ≤ x ≤ 175 | 平衡型 |
| x > 175 | 成长型 |

### 3. 基金风格综合判定

3×3 风格箱: 规模（大盘/中盘/小盘）× 价值-成长（价值/平衡/成长）

## 使用方法

### 命令行运行

```bash
# 分析中欧价值精选混合A
python main.py 021181

# 指定gamma参数
python main.py 021181 --gamma 0.5

# 分析其他基金
python main.py 000001
```

### Jupyter Notebook

打开 `ipynb/morningstar_stylebox_demo.ipynb`，按顺序运行所有单元格。

### Python脚本调用

```python
from main import main

# 分析单只基金
result = main('021181')

# 访问结果
print(result['fund_style'])       # 综合风格
print(result['fund_size_style'])  # 规模风格
print(result['fund_vg_style'])    # 价值-成长风格
```

## 关键设计决策

1. **市值门槛**: 使用实时全A行情计算LMT/MST，而非研报固定值
2. **价值因子**: 使用1/PE、1/PB等市场指标，替代研报的预期数据
3. **成长因子**: 使用PE偏离度等代理指标，因历史财务数据难以批量获取
4. **VG门限**: 使用全A VCG分布的33.3%/66.7%分位数

## 注意事项

1. 财务指标数据可能存在缺失，采用可用字段均值填充
2. 市值门槛每次运行基于最新行情计算
3. 价值-成长门限按全A股票VCG分布计算
4. efinance API可能因网络问题返回空数据，自动降级到akshare
