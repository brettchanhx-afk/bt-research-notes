# 基金评价因子及基金评价体系

基于华泰金工研报《基金评价因子及基金评价体系》完整复现。

## 研报来源

华泰证券研究所 - 金工研究 | 2020年

## 项目概述

构建完整的基金评价因子库（31个因子），实现因子回测、IC分析、因子复合、基金评分等功能。

## 因子分类（31个）

| 类别 | 因子 | 频率 | 方向 |
|------|------|------|------|
| 收益获取能力 | 年化收益率 | 月频 | 正向 |
| 风险控制能力 | 波动率、下行风险、最大回撤、回撤最大回补天数、VaR、beta | 月频 | 负向 |
| 风险调整收益 | 夏普比率、卡玛比率、特雷诺比率、索提诺比率 | 月频 | 正向 |
| 牛熊市表现 | 顺境收益率、逆境收益率、顺境/逆境战胜市场胜率 | 月频 | 正向 |
| 选股能力 | 单因子alpha、H-M模型alpha、T-M模型alpha | 月频 | 正向 |
| 择时能力 | H-M模型择时、T-M模型择时 | 月频 | 正向 |
| 规模变化 | 基金规模、基金份额、规模增长率、份额增长率 | 季频 | 负/正向 |
| 投资者结构 | 管理人员工持有占比、机构/个人投资者占比、户均持有份额 | 半年频 | 正/负向 |
| 交易能力 | 隐形交易能力、换手率 | 季频/半年频 | 正向 |
| 业绩持续性 | Hurst指数 | 月频 | 正向 |

## 核心模块

- `factor_calculator.py` - 31个因子计算
- `backtest_engine.py` - 回测引擎（分层回测、IC分析）
- `factor_composite.py` - 因子复合（等权、max_ICIR）
- `fund_scorer.py` - 五维基金评分模型
- `data_loader.py` - 数据获取（tushare/efinance/akshare）

## 评价维度

1. **窗口期判断** - 3/6/9/12个月对因子的影响
2. **时间敏感性** - 不同调仓路径的影响
3. **因子有效性** - RankIC、ICIR分析
4. **板块敏感性** - 不同板块的表现差异

## 输出指标

- RankIC均值、ICIR
- 年化收益率、夏普比率、最大回撤
- 调仓胜率、年化超额收益、信息比率
