# 多ETF轮动策略说明文档

## 一、策略概述

本策略是一个基于多只ETF基金的趋势与震荡双策略交易系统。它结合了动量轮动、RSI择时、ATR网格交易以及多种风险控制机制，旨在不同市场环境下获得稳定收益。

### 主要特点

- **多ETF轮动**：在多个ETF标的之间动态分配资金
- **双策略融合**：趋势策略（RSI择时）+ 震荡策略（ATR网格）
- **风险控制**：包含VaR、ES、涨跌幅限制、溢价监控等多重风控
- **定期调仓**：每月调仓一次，平滑换手

---

## 二、策略逻辑

### 2.1 标的池

策略涵盖多类ETF，包括：

| 类别 | 示例标的 |
|------|----------|
| 价值类 | 515520（价值100）、512040（中证价值） |
| 红利类 | 161907（中证红利）、512890（红利低波） |
| 宽基指数 | 510050（上证50）、510310（沪深300） |
| 海外/港股 | 510900（恒生国企）、513050（中概互联） |
| 商品类 | 518880（黄金） |

权重系数（1~10）用于调整各标的在仓位计算中的优先级。

### 2.2 仓位计算流程

1. **计算风险指标**：对每个标的计算ES（期望损失）和VaR（风险价值）
2. **计算成长率**：近21日涨幅
3. **综合评分**：结合ES、VaR、成长率、权重系数计算初始仓位
4. **平滑处理**：与历史记录加权平均（0.8新值 + 0.2历史值）
5. **排序选标的**：按仓位分数降序，选取前N只（默认5只）
6. **边界标的管理**：若边界标的发生切换，采用过渡处理
7. **涨跌幅过滤**：近期涨跌超过30%的标的需盘整巩固（幅度<5%后才解除）

### 2.3 RSI择时（用于卖出判断）

在`calctradeStockRatio`中，若某标的RSI > 30且计算仓位低于最低入选门槛，则将其仓位设0，防止追高买入。

### 2.4 ATR网格信号（辅助买卖判断）

在`buyOrSellCheck`中，结合RSI与ATR生成买卖信号：

| 条件 | 信号 |
|------|------|
| RSI > 卖出阈值（均值+1.4倍标准差） | 卖出 |
| RSI < 买入阈值（均值-1.4倍标准差） | 买入 |
| 收盘价 > 前日收盘价 + ATR | 卖出 |
| 收盘价 < 前日收盘价 - ATR | 买入 |

**阈值限制**：
- 买入阈值最高30
- 卖出阈值最低70

### 2.5 风控机制

| 风控项 | 实现方式 |
|--------|----------|
| 溢价/折价控制 | 溢价≥0.5%或折价≤-1%时禁止交易 |
| 单日跌幅限制 | 昨日跌幅在2%~4%之间时禁止当日交易 |
| 最大/最小仓位 | 单标的最多30%×倍数，最少10%×倍数 |
| 最小交易金额 | 2000元 |
| 债券固收兜底 | 剩余资金配置债券ETF（163210） |

## 三、调仓机制

### 3.1 调仓频率

- 每月一次（间隔≥30天）
- 且当前日为星期四（`weekDay={4}`）

### 3.2 调仓流程

1. 计算目标仓位`buyDict`
2. 计算当前持仓比例`holdDict`
3. 按目标与当前差值从小到大排序（差值小的先卖）
4. 先卖出需要减少或清仓的标的
5. 后买入需要建仓或加仓的标的

### 3.3 交易执行

```python
order_target_value(stock, quota)
```

- 每次调仓以目标市值下单
- 交易金额变化小于`minAmount`（2000元）则不操作
- 若目标仓位为0且当前有持仓，则清仓并记录实际收益率

## 四、关键参数说明

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `stockCount` | 5 | 最大持仓ETF数量 |
| `minRatio` | 0.10×Multiple | 单个标的最小仓位 |

| `maxRange` | 30 | 最大涨跌幅度（%） |

| `weekDay` | {4} | 调仓星期（周四） |

## 六、资金管理

- **每日注入**：`inout_cash(400)`，模拟每日定投400元
- **债券兜底**：剩余资金全部配置债券ETF（163210）
- **可用资金监控**：每日日志输出累计金额、可用资金、总资产

---

## 七、注意事项

1. **数据依赖**：需要聚宽（JoinQuant）平台的API支持，如`attribute_history`、`history`、`order_target_value`等
2. **溢价计算**：依赖`get_extras('unit_net_value')`获取基金净值，若数据缺失则返回0
3. **RSI参数**：`getStockRSI`使用7日，`buyOrSellCheck`中使用7日RSI+14日均值+14日标准差
4. **边界过渡**：`Transitional=True`时，对仓位排序边界标的使用平滑过渡，避免频繁进出
5. **延迟信号**：涨跌幅过大（>30%）的标的需要盘整巩固后才允许重新买入

## 八、策略优化建议

1. **参数优化**：可对`stockCount`、`confidenceLevel`、`maxRange`等参数进行网格搜索
2. **增加止损线**：建议增加固定回撤止损（如总资产回撤5%清仓）
3. **市场状态识别**：可加入均线排列判断趋势/震荡，动态切换策略权重
4. **成本优化**：当前佣金万三+滑点千二，可适当优化滑点设置
5. **另类数据补充**：加入波动率、成交量、资金流向等因子
