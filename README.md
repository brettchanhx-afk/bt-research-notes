# 量化策略研究项目

本项目汇集了近年来在资产配置、行业轮动、量化择时、因子投资、基金评价及回测框架等多个领域的量化研究策略与方法，涵盖来自多家券商的研究报告及公开资料整理。

## 目录结构

- `资产配置`：基于风险平价、Black-Litterman、宏观因子等模型的全球及大类资产配置策略。
- `行业轮动`：基于景气度、资金流、机构调研、动量等视角的行业轮动模型。
- `量化择时`：包括情绪指数、RSRS、波动率、鳄鱼线、HHT等多种择时模型。
- `因子投资`：涵盖CGO、筹码分布、聪明钱、APM、振幅、动量、凸显性等行为金融与微观结构因子。
- `基金评价`：基于晨星风格箱、Brinson、Campisi、Barra等模型的基金绩效归因与风格分析。
- `回测框架`：包括CSCV过拟合概率评估、Backtrader学习框架等。
